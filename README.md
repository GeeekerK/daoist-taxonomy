## 中文

### 为什么还要读书？——在 AI 时代

工艺在进步，生产效率在抬升。许多曾经「必须亲自动手」的基础工作，正在被 AI 接管：

- 写程序前的环境配置
- 甚至相当一部分「写代码本身」

但这并不意味着 **编码会消失**，也不意味着 **写作会消失**。

> **AI 永远是 assistant，只会辅助我们。**

当我们不必在琐碎的底层细节上消耗过多时间，省下来的注意力，更值得投向一件更慢、也更根本的事——**读书**。  
从这个角度看，读书不是「有空再做」的爱好，而是效率红利之后，更值得投入的主业之一。

### 书太多了，怎么办？

今天的书太杂、太多。很多人不是不想读，而是：

1. 不知道从哪本开始  
2. 分不清一本是在教「道理」、还是在教「操作」  
3. 读完了却说不清：它究竟在哪个层次上改变了我  

于是我想到一套更轻的分类法——来自道家传统的四个字：

# **道 · 法 · 术 · 器**

先把书分好层，再放进你的「天道」书架（实体 / 数字 / Kindle）。  
之后每次拿起一本，你会立刻知道：**它是在哪个层次上对你起作用。**

### 为什么不用传统学科分类？

传统学科分类很有用，但也容易让人迷路：哲学、文学、工学、医学、军事学……十几个大门类，条目细、边界多。

| 对比 | 传统学科分类 | 道法术器 |
| --- | --- | --- |
| 维度 | 按学科领域切块 | 按对「人」起作用的层次 |
| 数量 | 十几个甚至更多门类 | **4** 层 |
| 目的 | 便于图书馆编目与检索 | 便于个人读书、取用与成长 |
| 体验 | 「这本书属于哪一科？」 | 「这本书在改变我的哪一层？」 |

道法术器不是要取代图书馆学，而是给个人读者一把更锋利的刀：  
**少分类、看层次、服务自己的读书需求。**

## 道法术器四层 · The Four Layers

| 层 | Layer | 它回答的问题 | 对人的作用 | 典型书目（示例） |
| --- | :---: | --- | --- | --- |
| **道** | Dao | 世界 / 人生的根本道理是什么？ | 立方向、养格局、校准价值观 | 《道德经》、古典哲学、宗教与形上学、一流思想史 |
| **法** | Fa | 有哪些可复用的原则与框架？ | 形成方法系统，减少盲目试错 | 方法论、战略框架、认知科学、组织与制度研究 |
| **术** | Shu | 具体怎么做？步骤与技巧是什么？ | 提升可执行的技能 | 教程、手册、案例拆解、编程 / 写作 / 投资实务 |
| **器** | Qi | 用什么工具、载体、环境来落地？ | 放大效率，把术固定成习惯 | 工具书、软件文档、设备指南、工作流与模板 |

### 一句话记住

```text
道  →  为何 / 往哪走
法  →  按什么原则走
术  →  手脚怎么动
器  →  手里拿什么
```

### 同一主题，四层怎么分？（示例：学习编程）

| 层 | 例子 |
| --- | --- |
| 道 | 计算机如何改变文明；「计算」作为世界观 |
| 法 | 抽象、分层、工程化思维、算法思想 |
| 术 | 某语言语法、刷题、项目实战教程 |
| 器 | IDE、终端、包管理器、云平台、文档站 |

> 同一本书也可能跨层。先标「主层」，再标「辅层」即可——分类是为了启迪，不是为了审判。

### 如何服务你自己的读书需求

1. **建四层书架**：道 / 法 / 术 / 器（实体贴标，或数字文件夹同理）  
2. **每本书只问一句**：它主要改变我的哪一层？  
3. **按目标配比**：缺方向多读「道」；缺方法多读「法」；要上手多读「术」；卡在工具上再补「器」  
4. **读完写一行笔记**：`书名 | 主层 | 对我起了什么作用`  
5. **放入 Kindle（见下）**：让分类跟着你走，而不是停在脑海里

## 放入 Kindle · Into Kindle

这一节讲 **实操**：在 Kindle 里怎么命名、怎么建收藏夹，让「道法术器」真的能用起来。

### 1. 收藏夹命名（Collections）——推荐固定写法

在 Kindle 主页 → **收藏** → **新建收藏**，建这四个（名称建议原样复制，方便排序）：

| 收藏夹全名 | 简写 | 放什么 |
| --- | --- | --- |
| `01·道 Dao` | 道 | 根本道理、方向、价值观 |
| `02·法 Fa` | 法 | 原则、框架、方法论 |
| `03·术 Shu` | 术 | 步骤、技巧、实操教程 |
| `04·器 Qi` | 器 | 工具说明书、设备、模板、工作流 |

**命名规则（建议遵守）：**

1. **数字前缀 `01`–`04`**：保证在列表里按层次排序，不会被拼音打乱  
2. **中点 `·` + 汉字 + 英文**：一眼双语可读  
3. **不要改成「哲学」「计算机」等学科名**：收藏夹只表示「层次」，学科信息写在书名或笔记里  

可选第五个垃圾桶层（不计入四层）：

- `00·待分 Inbox` —— 新书先丢这里，周末再归层  

### 2. 单本书怎么命名 / 标注

Kindle 上多数书的官方书名改不了；用下面两种办法之一即可。

**办法 A（推荐）：只靠收藏夹，不改书名**

- 一本书可以同时进多个收藏（例如主层「法」、辅层「术」）  
- 主层必进一个；辅层可选  

**办法 B：在「个人文档」书名或笔记标题里加前缀**

若是你自己推送的 PDF / EPUB / TXT，推送前把文件名改成：

```text
[道] 道德经.md
[法] 思考·快与慢.epub
[术] Fluent-Python.epub
[器] Kindle-快捷键与批注手册.pdf
```

前缀规范：

| 前缀 | 含义 |
| --- | --- |
| `[道]` / `[Dao]` | 主层＝道 |
| `[法]` / `[Fa]` | 主层＝法 |
| `[术]` / `[Shu]` | 主层＝术 |
| `[器]` / `[Qi]` | 主层＝器 |
| `[法/术]` | 跨层：主法辅术 |

### 3. 设备上逐步操作（Paperwhite / Oasis / Kindle App 通用思路）

1. 打开书库 → 筛选 **收藏**  
2. 新建上述 4 个（+ 可选 Inbox）收藏夹  
3. 长按某本书 → **添加到收藏** → 勾选对应层  
4. 打开某个收藏夹 → 确认只看到该层的书  
5. 新书进库：先丢进 `00·待分 Inbox`，读两章或看目录后再归层  

### 4. 和 Calibre 联用时的命名（可选）

若用 Calibre 管理再同步到 Kindle：

- 用自定义列或标签：`layer:dao` / `layer:fa` / `layer:shu` / `layer:qi`  
- 发送到设备时，按标签生成与上面同名的收藏夹  
- 文件名仍可用 `[道]` 前缀，和收藏夹双保险  

### 5. 最小可行规范（抄这个就能开工）

```text
收藏夹：
  01·道 Dao
  02·法 Fa
  03·术 Shu
  04·器 Qi
  00·待分 Inbox   （可选）

自推文档文件名：
  [道] 书名.ext
  [法] 书名.ext
  [术] 书名.ext
  [器] 书名.ext
```

## English

### Why reading still matters in the AI age

Craft improves. Productivity rises. Many formerly basic chores are being absorbed by AI:

- setting up environments before coding  
- and even a large share of coding itself  

Yet **coding will not disappear**, and **writing will not disappear**.

> **AI is always an assistant — it assists; it does not replace the human core.**

When we spend less life-force on low-level friction, the surplus attention is best returned to something slower and deeper: **reading**.  
In that sense, reading is not a leftover hobby. It is one of the highest-leverage uses of the efficiency dividend.

### Too many books. Too little structure.

Books today are abundant and noisy. People often fail not from laziness, but from missing a map:

1. Where to start  
2. Whether a book teaches *principles* or *procedures*  
3. After finishing: *at which layer did it change me?*  

So here is a lighter taxonomy, borrowed from the Daoist fourfold:

# **Dao · Fa · Shu · Qi**

Classify first. Then place books into your personal “Heavenly Way” shelf — physical, digital, or **Kindle**.  
Every time you pick one up, you already know **which layer of you it is meant to work on**.

### Why not only use academic subject categories?

Library subject schemes are powerful — and often too heavy for personal reading: philosophy, literature, engineering, medicine, military science… a dozen doors, many walls.

| | Academic subjects | Dao · Fa · Shu · Qi |
| --- | --- | --- |
| Axis | Field / discipline | Layer of effect on a person |
| Count | Dozens of classes | **Four** layers |
| Goal | Catalog & retrieve | Orient, choose, grow |
| Question | “Which subject is this?” | “Which layer of me does this change?” |

This method does not replace librarianship.  
It is a personal blade: **fewer buckets, clearer layers, in service of your own reading life.**

### The four layers (quick map)

| Layer | Core question | Effect on you | Examples |
| --- | --- | --- | --- |
| **Dao** | What is fundamental? | Direction & worldview | Classics, metaphysics, first-rate intellectual history |
| **Fa** | What reusable principles / frameworks? | Method systems | Methodology, strategy, cognitive science |
| **Shu** | How exactly do I do it? | Executable skill | Tutorials, case studies, practice manuals |
| **Qi** | With what tools & media? | Leverage & habit | Tool docs, devices, workflows, templates |

```text
Dao → why / where to go
Fa  → by what principles
Shu → how the hands move
Qi  → what you hold
```

### Serving your own reading needs

1. Build four shelves: Dao / Fa / Shu / Qi  
2. Ask one question per book: *which layer is primary?*  
3. Rebalance by goal: lost → Dao; messy → Fa; stuck executing → Shu; tooling friction → Qi  
4. One-line note after reading: `title | layer | effect on me`  
5. **Put them into Kindle** so the map travels with you  

### Into Kindle — naming & filing (hands-on)

**Collection names (copy as-is for sort order):**

| Collection | Holds |
| --- | --- |
| `01·道 Dao` | fundamentals / direction |
| `02·法 Fa` | principles / frameworks |
| `03·术 Shu` | procedures / skills |
| `04·器 Qi` | tools / devices / templates |
| `00·待分 Inbox` *(optional)* | unsorted new titles |

**Rules:** numeric prefix for order; `·` + Chinese + English; collections encode *layer*, not academic subject.

**Per-book labeling:**

- Prefer Collections only (a book may sit in one primary + one secondary collection).  
- For self-sent files, rename before Send-to-Kindle:

```text
[Dao] title.ext
[Fa] title.ext
[Shu] title.ext
[Qi] title.ext
[Fa/Shu] title.ext   # primary / secondary
```

**On device:** Library → Collections → create the four → long-press a book → Add to collection → file new books via Inbox first.

**Calibre (optional):** tag `layer:dao|fa|shu|qi`, mirror the same collection names on sync.
